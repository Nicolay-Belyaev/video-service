# Следующая задача

## Простая авторизация через reverse proxy

Цель: не позволять посторонним запускать видеопотоки и расходовать платный трафик точки.

Согласованный подход:

- HTTP Basic Auth на reverse proxy (Caddy или nginx) перед Go-сервисом.
- Один общий логин и пароль; пароль хранится в виде хеша.
- HTTPS, чтобы учётные данные не передавались открытым текстом.
- Защищены сайт и все HTTP API, включая создание WebRTC-соединения.
- HTTP-порт Go-сервиса слушает только localhost, чтобы нельзя было обойти прокси.
- Браузер показывает стандартное окно входа; собственная форма входа не нужна.
- Без JWT, регистрации, базы пользователей и реестра сессий.
- Уже установленное WebRTC-соединение отдельно не отзывается.

Перед реализацией определить домен/способ получения TLS-сертификата и учётные данные.
Проверка результата: без авторизации нельзя открыть каталог или запустить поток;
после входа работают просмотр и переключение качества через fullscreen.

Статус: согласовано, реализация ещё не начата.
